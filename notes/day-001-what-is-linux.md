# Day 001 - What is Linux?

## 🧠 What is Linux?

Linux is an **operating system (OS)** that acts as a bridge between computer hardware and software applications.

In simple terms:
Linux makes your computer usable and manages all its core operations.

---

## ⚙️ What does Linux do?

Linux is responsible for managing:

- CPU (processing power)
- RAM (memory)
- Files and storage
- Running applications
- User and permission control

---

## 🌍 Why is Linux important?

Linux is widely used in real-world systems such as:

- Web servers (Google, Netflix, Amazon infrastructure)
- Mobile devices (Android is based on Linux)
- Cloud computing platforms
- DevOps and cybersecurity environments
- Supercomputers

---

## 💡 Key Features of Linux

### 1. Open Source
Its source code is publicly available and can be modified by anyone.

### 2. Free
Most Linux distributions are free to use.

### 3. Secure
Strong permission system and active community make it highly secure.

### 4. Stable
Linux systems can run for years without restarting.

---

## 🐧 Linux vs Windows

| Feature | Linux | Windows |
|--------|------|--------|
| Cost | Free | Paid |
| Open Source | Yes | No |
| Server Usage | Very High | Moderate |
| Customization | High | Limited |
